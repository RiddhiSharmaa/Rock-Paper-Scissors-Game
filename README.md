# Rock-Paper-Scissors-Game
✊✋✌️ Rock-Paper-Scissors Game
A fun and interactive Rock-Paper-Scissors game built with HTML, CSS, and JavaScript. Play against the computer and see who wins!

🎮 Features
🧠 Computer randomly picks Rock, Paper, or Scissors

👆 User-friendly button-based input

🏆 Instant result display: Win, Lose, or Draw

🎨 Clean and responsive UI

🔁 Play again with just one click

🛠️ Built With
HTML – Structure of the game

CSS – Styling and layout

JavaScript – Game logic and interactivity

🚀 How to Play
Open the website

Click on Rock, Paper, or Scissors

See what the computer chooses

Check the result instantly

Repeat and enjoy the game!
